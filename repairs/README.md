## 원인과 예방

- 본문 부재에도 RSS 요약으로 생성 요청을 보내고 파싱 실패 응답을 발행하던 경로를 차단했다. 200자 미만 본문, 길이 제한 중단 응답, 필수 교육 항목 누락은 실패로 처리한다.
- 뉴스1은 본문 전용 선택자가 없으면 페이지 전체 텍스트로 대체하지 않는다. 선택자가 변경되면 재수집/수동 확인이 필요하다. 길이 검증만으로 본문 진위를 완전히 보장하지는 않는다.
- 실패·처리 한도 초과 기사는 seen 목록에 넣지 않아 다음 수집에서 재시도할 수 있도록 했다. 별도의 영구 재시도 큐는 아니므로 RSS에서 사라진 기사는 수동 재처리가 필요하다.
- 날짜 목록의 배지 없는 링크를 다음 기사와 합치던 정규식을 수정했다. 이 결과 10월 21일의 3·4번도 원래 HTML에 따라 JSON에 개별 항목으로 나타난다. 3번의 기존 교육 콘텐츠 누락은 이 복원의 범위 밖이다.
- 전체 추출 점검에서는 기존 누락 3건(2026-06-07-1의 학생부 심화 아이디어, 2026-10-21-3 및 2026-10-24-5)이 별도로 보고된다. 이를 복원한 것으로 취급하지 않는다. 전체 추출 시 10월 24일 JSON에서도 기존에 숨겨졌던 항목이 드러나지만 이번 커밋에서는 해당 날짜 데이터를 변경하지 않았다.

검증: `python -m unittest discover -s tests -v`; `node tools/extract_json.mjs`; `node tools/normalize.mjs`. 테스트는 외부 API·자격증명 없이 실행하며 목록 경계, 본문 부재, 필수 항목·질문 답변 정합성, 복원 원본→HTML→JSON 일치를 확인한다.
